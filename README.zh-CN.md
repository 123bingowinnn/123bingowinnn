## 精选项目

### 触手可剧

一个第一人称互动短剧原型，让用户通过点击、长按、拖动等场景内动作推动剧情。我们还把 AI 剧本、分镜和视频生成流程整理成了可复用的生产 Skills。

项目获得抖音 AI 创变者计划黑客松**全国三等奖，团队奖金 3 万元**。

[项目介绍与演示](https://bingosun.vercel.app/projects/chushou-keju)

### 归程

一个由四人团队共同完成的黑客松项目，关注生命、失去，以及告别时需要处理的实际事务。我们做了一个原型，帮助家属整理办理步骤、所需材料和进度，并提供具体城市的信息和可核对的来源。

[查看团队代码](https://github.com/123bingowinnn/death-education-hackathon)

### Another Me

温州黑客松的团队原型。情绪变成一颗蛋，再孵化为数字伙伴；有相似感受的人也可以在共享空间里交流。我们通过移动网页探索了从发现情绪、孵化伙伴到分享的完整流程。

[黑客松项目](https://github.com/123bingowinnn/Hackthon) · [像素小猫实验](https://github.com/123bingowinnn/another-me)

### UnNote

一个无需离开当前工作就能捕获任务的 macOS 应用。输入想法、说句话或截一张图，应用就能将其整理成结构化待办。我设计并开发了捕获流程、原生界面和 AI 指令路由，支持本地存储和可撤销操作。

[查看代码](https://github.com/123bingowinnn/UnNote)

### 冰箱里面有什么

一个记录食材和保质期的 Web 应用。我围绕两个日常问题来设计它：冰箱里已经有什么，接下来应该先用什么？通过个人食材库存和到期时间记录，让每天的厨房决策更简单。

[在线体验](https://fridge-clear.vercel.app/)

### Vibe Paper

一个把 LaTeX 论文和实验代码放在一起的本地工作区。Coding agent 可以结合实际文件和实验结果工作，通过本地编译与 PDF 预览，让论文写作紧贴实验本身。

[查看代码](https://github.com/123bingowinnn/vibe_paper)
