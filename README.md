I'm **Xubin (Bingo) Sun / 孙徐斌**, a Computer Science master's student at Yale. I build AI product prototypes and tools I can use in my own work, with an interest in how people interact with them.

My projects include a macOS capture app, a workspace for writing papers with coding agents, and tools for reproducible experiments.

### Selected work

| Project | What it does | Built with |

| **[Vibe Paper](https://github.com/123bingowinnn/vibe_paper)** | Write LaTeX papers alongside experiment code with a local compile and preview loop. | Python · LaTeX |
